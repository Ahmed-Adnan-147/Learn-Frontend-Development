 * BOX MODEL IN CSS: 
   -> Box model consists of content, padding, border, margin.
   -> The blue part in the box is the content area, green part is padding, yellow part is the 
      border & orange part is the margin.
   -> Inside the content, we can display the width & height of the content respectively as
       640x300, where 640 is the width and 300 is the height respectively.
   ---------------------------------------------------------------------------------------------
   * Understanding & playing with height & width:
     -> lets take two divs, and give the bg color as red & blue. As div is a block level element,
	    when u open Devtools and try to play with it the width gets changed accordingly. But the 
		height remains the same bcoz the height will be according to its content in it.
	 -> Block level elements covers full width of the viewport and the height changes according
	    to the content in it. If we give lorem100 to div1 then the height will get updated to the 
		content in it and gets bigger.
		NOTE: The height is automatically calculated by the browser according to the content size
		      in it.
	 -> If we give width as 500px to div1, then the width & height will get fixed, when we reduce 
	    the viewport, the content will overflow, the div will get the horizontal scroller and 
		gets overflow in it as the width is fixed to 500px.
	 -> This is called overflow.
	 
   ---------------------------------------------------------------------------------------------
   * Why you should not give Absolute Height & width:
     -> In CSS, "absolute height and width" refers to setting the dimensions of an element using 
	    absolute length units. These units are fixed and do not change based on the size of the 
		viewport or parent elements. 
		- Absolute Length Units: px, cm, mm, in, pc, pt etc.
		
   ---------------------------------------------------------------------------------------------
   * Why should you use "max-width" Property:
     -> When u use max-width: 500px, instead of width, then the width doesn't exceeds 500, but when
        we reduce the viewport, then the width reduces and the height increases accordingly, so 
        the content will not overflow, and we'll not get scrollbar.
		
   ---------------------------------------------------------------------------------------------
   * Understanding Height in CSS:
     -> But if we set both height as well as the width, then the overflow happens vertically, so 
	    in this case you can give min-height as given below:
		.one{
		  max-width: "500px";
		  min-height: "300px";
		}	
     -> If we give min-height then if this exceeds 300 then the height will increse instead of 
        overflow.
     -> we can also use overflow property instead of min-height, but we will learn that in next 
        videos. Btw, the default value of overflow: visible; 
     -> we can also change it to overflow: hidden;	

   ---------------------------------------------------------------------------------------------
   * Use CSS Percentage Unit for width:	
     -> we can also use the width: 50%; This will change and make the width to 50% of the parent 
	    and not the viewport. So in this case the body element is the parent, and by default, the 
		body has the width 100% according to the viewport. 
     -> when we reduce the viewport to its last, then few words gets overflow from it, so we can 
        use  word-break: break-all; which breaks the words.

   ---------------------------------------------------------------------------------------------
   * Understand Width in Percentage:
     -> NOTE: The % takes the width from its parent instead of viewport.
	    NOTE: Make sure to avoid using the width unit as px to the parent, instead use %.

   ---------------------------------------------------------------------------------------------
   * Understand Height in Percentage:
     -> It is compulsory in height case , that the height should be given to the parent else it 
	    won't take , but in case of width, if we don't give the width to the parent, still it takes
	    NOTE: if u give the height to the parent element then only it applies to its children else
		      if u just give height to the child, then the height doesn't gets apply in case of %.
	 -> the height which u give to the parent should be in absolute value i.e., in px, then it works
	    for its child.
		NOTE: the % height will only work if its parent has a height in absolute units which is px.
	
   ---------------------------------------------------------------------------------------------
   * Introduction to Padding:
     -> it gives space b/w the content and the border.
	 -> The padding comes inside the containers width & height, if we add padding it affects the 
	    height & width of the actual container, the height & width of the actual container gets 
		increased if we add padding & border to the container. You can check this while hovering to
		the element, in the UI , u will display.
	 -> To overcome this issue, we give box-sizing: border-box; so this will reduce the width & 
	    height of the actual container & adds the padding & border inside it.
	 -> If we give border the element size gets increased, and the height width will also get 
	    bigger.
	
   ---------------------------------------------------------------------------------------------
   * What is the problem with "box-sizing":
     -> Now the height & width has been increased to 450px width & 260 in height, so to overcome 
	    this we use box-sizing: border-box; , it reduces the height & width if we give the padding 
		& border to the element, the height will get increased and the width will get reduced.
	 -> so the border-box will set the width inside the width given for the actual element.
	 -> As the actual element content width exceeds or finishes, then it starts increasing the   
	    actual height width again by increasing the width.
		
   ---------------------------------------------------------------------------------------------
   * What is Universal selector in CSS:
     -> So, whenever we start to build the project, we use universal selector and set the box-sizing
	    to it. so, universal selector sets all the elements box-sizing to border-box.
		
   ---------------------------------------------------------------------------------------------
   * What is margin in CSS:
     -> The margin is not included in our elements width. It is added outside the width of the 
	    actual element.
	 -> margin doesn't affect the height & width of the actual element, because it is applied 
	    outside the actual element/container.
	 -> By default the body element has some margin, so we can given the margin as 0 to the body
	    element.

   ---------------------------------------------------------------------------------------------
   * Understand border-radius in CSS:
     -> we use this to round the elements corners.
	 -> we can also make use of 50% border-radius so it becomes ellipse, to make it to circle, we
	    give height & width to the container and then add 50% border-radius to it. So in this case
		we need to give height to the container.
		
   ---------------------------------------------------------------------------------------------
   -> We can also give negative margin to the container, it will get nearer instead of going far.
   -> we can fit the image in a container which is a circle by giving overflow: hidden;
